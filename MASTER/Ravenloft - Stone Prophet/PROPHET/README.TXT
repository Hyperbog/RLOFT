CHARACTER INVENTORY SCREEN

When replacing NPC's and dead PC's with the desert troll, items in the top 
four inventory slots of the character being replaced will be lost. Make sure
that the items in these slots are removed or transfered to another character 
before picking up the desert troll.

CHARACTER TRANSFER

Please refer to the rulebook on page 35 on how to transfer characters.

A WARNING TO DISK CACHE USERS

SMARTDRV will not work properly with Ravenloft: Stone Prophet in its normal
configuration.

You can:

1. Remove SMARTDRV (you can do this by creating a boot disk.)

2. Remove SMARTDRV's write cache by typing SMARTDRV followed by the hard
   drive letter.

   Example: SMARTDRV C (enter)

   This will remove the write cache on your C: drive.  If you have more
   than one hard drive, repeat  this command for each drive.  So, if
   you have a C: and a D:, you would type:

   SMARTDRV C (enter)
   SMARTDRV D (enter)

OTHER DISK CACHE PROGRAMS:

Any program that has a write cache enabled is prone to data loss.  Remove
the write cache or remove the disk cache program from your configuration
(you can do this by creating a boot disk).

If you do not take the above precautions, you may exhibit data loss!

OBJECTS WITHIN URNS

When an urn contains an object which can be picked up by the party, the
cursor changes to the golden hand icon when it passes over the urn.  A
right-click picks the object out of the urn. 

USE OF SPECIAL OBJECTS

The Tears of Ra, the Hero's Heart, and the Mallet (for striking the gong in
Pharaoh's Rest) are used by placing the object in a character's hand, facing
the party toward the place of use, and left-clicking on the in-hand object.

Example: with the mallet in-hand, the party faces the gong.  Left-click on
the in-hand mallet to strike the gong.  The Tears of Ra are used in the same
way while facing the locations in which the tears are to be placed.

The Hero's Heart can also be used as a key.  With the object on the cursor,
click over the location where the Hero's Heart is to be used to open the
door with the portrait of the Hero on it.

OFFERING OBJECTS TO NPCS

When offering an object to a Non-Player Character, the objects must be on
the mouse cursor.  With the object on the mouse cursor, place the object
over the NPC and  left-click   Examples of this are the Magical Watering
Urn which is offered to the Priest at the Ruined Temple of Harvest and the
Iron Set Idol Keys which are offered to the Invisible Watchers of Set in
the Temple of Set.

READYING THROWN WEAPONS

Under Combat Strategies in the manual, the text reads "Characters who use
thrown weapons should carry them in hand.  A shield or short sword in that
position is readied automatically after the character attacks with the last
of his or her thrown weapons."  This is does not occur.  When a character
uses a thrown weapon, any identical thrown weapon free in inventory is
readied automatically for throwing.  Weapons in sacks or other containers
are not readied for throwing in this manner.

CHARACTER SHEET

To move the position of a character in the party, left-click on the
Character Portrait, and then left-click over the new position.  If
another Character occupies the desired position, the two characters will
switch position.

To change a player character's name, left-click on the Character Sheet.
Type in the new name (up to 12 characters long) and hit Return to enter
the new name.  At any time before you hit return, you may hit escape to
return the original name to the character.

The F1 through F4 keys provide a short cut to placing objects in inventory.
When an object has been picked up and is on the mouse cursor, pressing the
F1 key places that object in the inventory of the character furthest to the
left on the Character Sheet.  F2 places the object in the inventory to the
right of the first character, etc..

CINEMATICS

Some cinematics in the game require more than the specified memory to get
full voice.  These include the opening, history of Anhktepot and the ship
ride beyond the Gate of the Dead.  The memory required for this is
3,800,000 bytes free XMS.
