# Windows 11 Ravenloft Asset Extractor

The **WPF Fluent Asset Extraction Suite** is the supported/default
application. The old single-file Tkinter EXE and its ZIP have been retired.

**[Download the latest Windows 11 ZIP](https://github.com/Hyperbog/RLOFT/releases/latest/download/RavenloftExtractor-Windows11-x64.zip)**

Extract the complete ZIP and launch `RavenloftExtractor.exe`. Do not launch
the frontend EXE without its companion runtime and backend files.

The distribution lives in GitHub Releases because the self-contained .NET
frontend/backend ZIP exceeds GitHub's normal single-file Git object limit.
`Tools/WpfExtractor/` is the reproducible source and local build script.

Original legacy binaries can be recovered from repository history if needed
for comparisons, but are no longer current or published from this directory.
