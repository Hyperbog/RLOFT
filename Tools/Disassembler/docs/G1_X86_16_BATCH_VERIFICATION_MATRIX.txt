REQUIRED SYNTHETIC ACCEPTANCE CHECKS
------------------------------------
A. Existing near16 table baseline remains stable:
   - CMP BX,imm8/imm16, JA/JAE not-taken range, near CS:[BX+disp16].
   - CMP AX/CX/DX/SI/DI plus exact MOV BX,reg; wrong-copy rejection.
   - Sign extension, signed condition, negative displacement and
     wrap/backing checks.
B. New unsigned branch directions:
   - Short and near16 JB/JBE taken-edge selection; inclusive/exclusive
     entry count correctly derived from original CMP.
   - Both edges match original relative branch bytes, with a distinct
     decoded non-dispatch exit.
   - Wrong condition, bypass/merge, artificial extra edge, invalid
     graph entry and tampered branch destination are rejected.
C. Unique, byte-backed paths:
   - NOP, JMP rel8 and JMP rel16 bridges with a bounded hop count.
   - Altered source offsets/bytes, forged nonadjacent fallthrough,
     competing predecessor, unsafe mutation and over-budget chain
     do not authorize a candidate.
D. Exact comparison/stride encodings:
   - Accumulator CMP AX,imm16 (3D iw) plus proven MOV BX,AX.
   - SHL BX,1, ADD BX,BX (both encodings), SHL BX,2, two linked
     doublings for four-byte FAR pointers.
   - Wrong register, single insufficient far doubling and large
     immediate do not produce validated table targets.
E. Pointer and storage evidence:
   - Every near entry maps to source-backed same-segment storage.
   - Every far entry has a unique exact MZ selector fixup and explicitly
     requested load segment. Missing selector proof fails closed.
   - Rejected data/code overlap yields no automatic CFG seeds.
F. New reporting and graph-integrity checks:
   - Forged instruction.FlowControl labels for RET/CMP/SHL/NOP
     are rejected even when the byte stream is unchanged.
   - Duplicate decoded starts return unresolved instead of throwing.
   - The rejected conditional exit is byte-backed and unique.
   - Rejected candidate has null EntryCount, null StoredTable,
     and an explicit pointer-validator rejection reason.
   - Truncated graph and >128 sites have distinct report indicators
     and bounded per-site output without silent loss of totals.
G. Unaffected functionality remains green:
   - All existing synthetic LE page/fixup/CFG cases.
   - DOS MZ/COM nested launcher separation and cross-segment checks.
   - Project SQLite round-trip/backup, diagnostic privacy and CLI.
   - Desktop compilation remains green; no manual UI testing is
     needed unless G1 actually changes a user-visible behavior.

FAIL-CLOSED / RELEASE BLOCKERS
------------------------------
- Compiler/smoke failure or an exception on deliberately malformed
  graph input that should instead remain unresolved.
- Reported verified executable reachability from candidate table entries.
- Any source-identity mismatch accepted, original storage overwritten,
  code/data conflict silently ignored, or missing MZ relocation accepted.
- A public CI workflow left enabled on pushes/pull requests.
- A status presented as tested when only static source review occurred.
