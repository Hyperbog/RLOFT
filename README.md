# DOSDis — multi-platform game disassembler

**Branch:** `DosDis`. The Windows WPF desktop is the application; the CLI is an internal independent-testing harness. Supported research targets include DOS/x86, NES/6502 and Sega Master System/Z80, **with documented partial ISA/mapper support**; more consoles are future work.

[Tool entry and build guide](Tools/Disassembler/README.md) · [Platform limitations](Tools/Disassembler/docs/MULTIPLATFORM_CORE_PLAN.md) · [Independent validation](Tools/Disassembler/docs/INDEPENDENT_VALIDATION_POLICY.md) · [Current checkpoint](Tools/Disassembler/docs/CURRENT_CHECKPOINT.md) · [Original chronology](Tools/Disassembler/README_HISTORY_20261017.md).

Candidate code/data, xrefs, labels and byte matches do **not** establish actual game execution. Original ROM/EXE data remain private to the owner's machine. The DOSDis [draft PR #27](https://github.com/Hyperbog/RLOFT/pull/27) remains open.
