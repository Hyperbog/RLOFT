# RLOFT — original-source recompilation

**Branch:** `recomp`. Independent source recompilation workstream using reconstructed [CODE.1](Code1/README.md) and [CODE.2](Code2/README.md) inputs. This is **not** the native playable game; see [`demo-v1`](https://github.com/Hyperbog/RLOFT/tree/demo-v1/DemoV1).

Start at [Recomp/README.md](Recomp/README.md) for Windows x64 CMake, compiled source link/entry testing and precise current limits. [Branch guide](Recomp/BRANCH_GUIDE.md) explains separation from decompilation; original DOS runtime parity and complete DOS game boot remain unverified.

**Project coordination:** [branch map](https://github.com/Hyperbog/RLOFT/blob/code1-decompilation/docs/BRANCH_OWNERSHIP.md), [source ID register](https://github.com/Hyperbog/RLOFT/blob/code1-decompilation/docs/SHARED_SOURCE_REGISTER.md), and [generated CI/head data](https://github.com/Hyperbog/RLOFT/blob/code1-decompilation/docs/LIVE_STATUS.md).

Do not commit proprietary original files. Use exact binary/address proofs when reconstructing behavior. Engine gameplay acceptance and source CI acceptance are distinct.
