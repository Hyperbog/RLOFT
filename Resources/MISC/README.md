# Miscellaneous resource/support files

This family holds supplied files that do not yet justify a separate top-level format family:

- `COLORS`
- `INIT`
- `SAMPLE.AD`
- `SINTAB`
- `T`

Each has its own subdirectory and immutable source identity. Files can be promoted into a dedicated family later if executable analysis establishes a distinct format or subsystem that benefits from separation.
