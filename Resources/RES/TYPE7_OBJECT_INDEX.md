## Allocation observations

- The class-2 bank contains 842 resources (`RES3:3316..4157`).
- The largest supplied base/stride endpoint is `834 + 8 = 842`, closing the bank exactly.
- The supplied database contains 121 unique local bases and 123 unique `(base,stride)` pairs across 336 definitions.
- `+0x2A` is a shape-subrange stride, not a universally simple heading stride. CODE.2 first applies the live three-bit scene-variant selector, then the common scene helper can select a view/state-dependent subframe within that stride.
- Normal family-C level loading clears runtime variant bits 6..8; thrown-item creation also clears them. No class-2 periodic variant-cycle path analogous to NPC/class-1/class-3 cycling has been proved, so class-2 variant semantics remain intentionally generic.
