# BNK resources

Workspaces for the supplied `GM1.BNK` and `GM2.BNK` files.

The `.BNK` extension and filenames suggest an audio/music bank role, but that semantic label is not yet treated as confirmed. Analysis must identify the executable consumers, file signatures/records, and any relationship to the game's MIDI/FM/driver paths before assigning field meanings.

Both originals have immutable size/SHA-256 records in their child directories.
